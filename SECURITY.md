# Security Policy

kusamushiri runs locally and stores browser sessions only on your computer.
If you find a vulnerability (for example, session data exposed to other users or sent
anywhere other than x.com), please report it privately through
[GitHub Security Advisories](https://github.com/kw4r3n/kusamushiri/security/advisories/new)
instead of opening a public issue.

Only the latest release is supported.
